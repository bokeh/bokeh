3.10.0
======

Bokeh version ``3.10.0`` (August 2026) is a minor milestone of the Bokeh
project. This release requires Python 3.12 or newer.

Features
--------

* Added WebGL rendering support for ``Patch`` and ``Patches`` glyphs
  (:bokeh-pull:`14853`)
* Added framework-neutral ASGI server support, allowing Bokeh applications to
  run with frameworks such as FastAPI, Starlette, and Django without requiring
  Tornado (:bokeh-pull:`15239`, :bokeh-pull:`15295`)
* Added Playwright as an alternative backend for exporting plots to PNG and SVG
  (:bokeh-pull:`14940`)
* Added ``Server.from_settings()`` for constructing a server from global Bokeh
  settings (:bokeh-pull:`14874`)
* Added optional dependency groups, including ``pip install bokeh[all]``
  (:bokeh-pull:`14924`)
* Added ``CustomJS.from_template()`` for constructing callbacks with Python
  template strings (:bokeh-pull:`14978`)
* Added the ``"ignore_viewport"`` autosizing mode to ``DataTable`` and improved
  per-column sizing with ``autosize_mode="fit_viewport"``
  (:bokeh-pull:`15201`, :bokeh-pull:`15160`)
* Improved old-style extension support by allowing imports from
  ``@bokehjs/...`` modules (:bokeh-pull:`15250`)
* Improved initial ``Tabs`` loading performance by rendering only the active
  tab initially and retaining materialized tab views (:bokeh-pull:`15205`)

Bug fixes
---------

* Fixed WebGL rendering issues involving property overrides, streaming updates,
  polygon topology, nested rings, and invalid dash patterns, including browser
  hangs caused by all-zero dash patterns (:bokeh-pull:`14895`,
  :bokeh-pull:`15255`, :bokeh-pull:`15257`, :bokeh-pull:`15259`)
* Fixed hover and selection behavior for ``Step`` glyphs and improved hit
  testing and panning performance (:bokeh-pull:`14737`, :bokeh-pull:`14880`,
  :bokeh-pull:`15083`, :bokeh-pull:`15109`)
* Fixed several ``DataTable`` rendering and update problems, including initial
  row rendering, propagation of ``ColumnDataSource`` updates, synchronization
  of selections, visibility changes for dynamically added columns, rendering
  with shared glyphs, and unreadable fitted columns (:bokeh-pull:`15133`,
  :bokeh-pull:`15136`, :bokeh-pull:`15138`, :bokeh-pull:`15183`,
  :bokeh-pull:`15190`, :bokeh-pull:`15200`)
* Fixed client-side lifecycle and memory leaks so that removed models, plots,
  widgets, menus, and replaced child views are released promptly
  (:bokeh-pull:`15291`, :bokeh-pull:`15298`, :bokeh-pull:`15299`)
* Fixed canvas rendering of ``Wedge`` and ``AnnularWedge`` glyph property
  overrides (:bokeh-pull:`14952`)
* Hardened credentialed ``autoload.js`` CORS responses by restricting origins
  to the configured websocket-origin allowlist (:bokeh-pull:`15105`)
